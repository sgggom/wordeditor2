# 方格 · 关卡编辑器

第一阶段：选择行数（2 或 3）与列数（3、4 或 5），即时生成网格棋盘。

- 默认尺寸为 3 行 × 4 列，共 12 格。
- 支持全部 6 种尺寸组合，格子始终保持正方形。
- 当前尺寸会保存在浏览器本地；刷新后恢复。浏览器禁止存储时仍可使用编辑功能。
- 点击「恢复默认尺寸」回到 3 行 × 4 列。
- 适配桌面和手机，尺寸选项支持键盘操作。

## 打开

可直接双击 `dist/index.html`，不需要安装依赖。

也可在此目录运行：

```sh
npm run dev
```

然后打开 http://127.0.0.1:4173 。需要使用其他端口时运行 `PORT=4174 npm run dev`。

直接打开文件和通过 HTTP 访问属于不同的浏览器存储空间，尺寸设置各自保存。

## 文件

- `dist/index.html`：编辑器页面。
- `dist/styles.css`：界面、棋盘和响应式布局。
- `dist/app.js`：尺寸约束、棋盘渲染与本地保存。
- `scripts/serve.mjs`：仅监听本机的开发服务器，无第三方依赖。

运行 `npm run check` 检查 JavaScript 语法。本阶段仅编辑棋盘尺寸，格子内容留待后续功能扩展。
