# 方格 · 关卡编辑器

编辑器仅在本地开发和运行。关卡库使用当前浏览器的 IndexedDB，配置列表和新关卡默认值使用 localStorage。清除浏览器数据前，请备份关卡和配置。未经明确要求，不推送远程、不发布站点、不创建本地版本提交。

## 快速开始

在 `level-editor/` 目录执行：

```sh
npm start
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:4173`。通过本地服务访问，不直接双击 HTML。运行需要 Node.js；编辑器面向电脑浏览器。

```sh
npm run check
npm test
```

## 当前2000关规则生成

打开“关卡配置列表”，选择“当前规则 · 2000关 · 三成造型 · 长词与路径节奏优化”，再选择生成范围。已有配置列表保留；新规则列表独立加入。每10关第1、3、7关镂空，其余7关完整矩形；首关固定CAT／ALL的T型计入第一组3关。镂空造型前10关去重，最后500关循环对应参考配置。

生成器始终保留指定禁用格，失败不会改成完整盘。目标使用候选白名单、至少3字母、1～4档，禁止直接加S的目标词对；完整游戏词库用于额外词枚举。程序在有限候选中比较词量、词长、生僻度、转弯和入口分布；这些体验指标保留真实偏差，不保证每项与参考精确一致。

路径按参考阶段匹配直线、1拐、2拐、3拐及以上的分布，避免每个词都向平均拐弯数靠拢。词长细分3～8+字母，优先为参考长词留出摆放空间；每加入一个目标词后重新评估剩余分布。最多比较32个安全候选盘，报告实际词量、词长与拐弯分布的偏差。

也可直接生成独立文件：

```sh
node scripts/generate-current-rules.mjs --from 1 --to 20 --seed 20261104 --out ../outputs/current-rule-trial
```

中段续做可加 `--history 历史文件.json`，支持draft数组、编辑器records和游戏books/daily。输出游戏文件、可编辑数据、每20关的草稿检查点和质量报告；报告会标明前序历史是否完整。原50关预设保持不变。

### 先摆核心词，再挑选成品

模型先写出每关的核心词及其索引路径，示例见 `../outputs/20261105-anchor-pool-trial/anchors.json`。在本目录执行以下命令可生成候选和导出复选结果。

```sh
node scripts/generate-anchor-candidates.mjs pool ../outputs/20261105-anchor-pool-trial/anchors.json ../outputs/20261105-anchor-pool-trial/results
node scripts/generate-anchor-candidates.mjs pick ../outputs/20261105-anchor-pool-trial/anchors.json ../outputs/20261105-anchor-pool-trial/results ../outputs/20261105-anchor-pool-trial/picks.json
```

每关默认收集100张不同且可通关的棋盘，核心词位置固定。先看 `word-options.txt` 里的补词，再从 `pool.json` 查看入围棋盘的路径和候选ID。将每关选中的ID与理由写入 `picks.json`，运行 `pick` 会合并实际选择，复查前后10关目标词、重复整盘、核心路径、额外词和通关安全，输出 `selected-game.json`。

固定词占满有效格时收集一张棋盘。其余关受搜索次数与时间上限约束，候选池记录实际数量和停止原因。任务中的 `history` 路径相对于任务文件，接受带原始关号的游戏导出；已知历史参与查重，缺少的前序关号列在结果中。

## 界面组成

左侧顶部表单显示当前关卡或已载入配置的生成参数：尺寸、正向概率、两项查重范围、目标数量、固定词和词库筛选，下方是单词表、棋盘和关卡统计。右侧关卡列表独占整列，从顶部导航下方延伸到底部，列表独立滚动。

- 点击已有关卡，恢复它的棋盘和生成参数。查看关卡不会改变新关卡默认值。
- 顶部“试玩”在界面左侧打开当前关卡，右侧关卡列表保持可点击，也可用上下方向键切关；切换后试玩同步载入所选关卡并重新开始，重复点击当前关卡保留试玩进度。可拖动连词后松手提交，也可依次点击字母再提交。目标词扣除实际连线路径的格子次数，额外词只收集一次、不扣次数；次数归零的格子不能再选。所有目标词和格子次数清空后通关。支持重玩、显示答案和 Esc 关闭；试玩不修改编辑关卡或已保存数据。
- 修改参数保留当前棋盘，并提示“重新生成后生效”。保存关卡保存当前结果；需先重新生成才能将新参数应用到棋盘。
- 选中已有关卡后重新生成，结果为未保存修改，点击“更新关卡”更新原位置。未选中关卡时保存到末尾。
- “新建空白关卡”取消选中，恢复新关卡默认值并清空固定词、固定位置、豁免和目标数量。本地文件模式也支持新建追加。
- 新建草稿时调整尺寸、正向概率、查重范围和筛选，会记为新关卡默认值；固定词和目标数量只跟随关卡或配置。
- “编辑固定词”复用棋盘编辑器，可编辑固定词、路径和棋盘造型；“清除固定词”清除固定词、路径和豁免。
- 普通点击棋盘仅高亮格子；开启“编辑造型”后才切换禁用格。修改造型后需重新生成。缩小棋盘会保留仍有效的固定路径，越界或碰到禁用格的词改为自动摆放并保留词名。
- 点击单词高亮路径。词表允许手动勾选目标词，固定词不能取消，移除后必须仍有目标词覆盖每个启用格子。
- 关卡列表支持新建、重命名、切换、删除以及关卡上移、下移、删除。列表互相独立；至少保留一份。列表获得焦点后可用 ↑ / ↓ 切换关卡。

“关卡数据”只显示统计；单关 JSON 的读取和复制放在“关卡文件与预设”中。

## 生成规则

行列均支持 2～5，默认 3 行 × 4 列。单词沿上下左右相邻格子排列，可拐弯，同一词不能重复用格，不同词可共享字母。最终目标词必须覆盖全部启用格子，游戏格式每格最多使用 35 次。

固定词既是生成约束也是目标词。固定位置先写入，自动摆放的固定词随后放入，最后补满棋盘。固定词必须满足词库、筛选和查重规则。固定词摘要标明查重豁免；豁免仅适用于明确记录的固定目标词。

仅第 1 关允许两字母词；第 2 关起至少三个字母。“2词库”在后续关卡置灰。关联配置的单关与批量生成按配置位置判断是否第 1 关，即使只运行中间一段也不视为开场关。

“初始正向概率”是 0～100 的整数，默认 50%。生成优先覆盖更多空格，再选择路径分最低的合法摆法；同等条件下按概率偏向右 / 下，或左 / 上。后续词无法摆放或棋盘存在消词死局时，会撤销前序摆放并尝试其他路径、覆盖数量和单词。每轮限制回溯候选数量，再换一轮随机顺序继续搜索。路径分由首向、拐弯和同轴折返组成；不保证结果的实际正向词占比等于该值。

“目标数量”为尽量达到的数量，0 不自动补选。生成先保留初始词，再从合格候选词中按实际路径分由低到高补选。候选不足接受实际数量，不为数量不足重试。补选仍遵守筛选、查重、后续固定词预留和格子计数限制；会引入消词死局的候选保留为额外词。

目标词和额外词分别查重，默认各前 20 关，0 关闭对应类别。编辑已有结果仅比较当前位置之前的 N 关，新关比较末尾 N 关；当前关和后续关不进入历史。保存修改也检查重复，手动勾词不能绕过。

目标词查重严格执行，历史重复词在铺盘前排除；明确豁免的固定词保留豁免。额外词优先零重复，累计尝试超过 10 万次后允许采用额外重复词最少且通过通关检测的合格结果，保留 `extraDuplicateFallback` 记录。未手动改变选词的结果保存时沿用该回退记录；目标词重复不会因此放行。

单关与批量使用逻辑核心数减 1 个 Worker，至少 1 个。生成持续尝试直到成功，支持停止；可用词已耗尽或搜索已穷尽仍没有安全摆法时明确报错。停止或失败保留上一个结果。批量按配置顺序逐关生成，成功保存后才进入下一关，后续历史包含本轮已保存结果。

自动生成的初始目标和每次补选都检查所有合法消词选择能否完成，存在死局的结果不返回、不自动保存，也不进入额外词回退候选。每放入一个初始词就检测当前已放入的词；若已形成死局，立即回溯，不再为这个分支尝试补满棋盘。不同路径使用不同格子但仍能完成的情况允许通过。已有文件与手动选词继续使用原有检测提示和修复入口。

情绪分或生僻数据仅用于展示和警告，不额外阻止生成、保存和导出。目标词、字母或格子使用次数变化会触发单关无解检测；路径高亮不改变检测输入。

“全部检测”只更新检测结果。发现问题后显示“修复问题关卡”，点击后列出替换关号和配置来源，确认才重跑。修复结果必须通过无解复检才替换；停止保留未修复原关和已成功结果。游戏文件缺少生成参数时需读取匹配的 XLSX / CSV 配置表。预设只读，不能修复写入。

## 配置列表

“关卡配置列表”支持多列表、新建、重命名、复制、删除、批量设置、载入单关、运行所选和按范围生成。每份最多 1500 行；内置参考配置独立于本地关卡版本。新增行默认为 3×3，无固定词与路径，筛选继承上一行，空列表使用当前编辑器筛选。

配置修改为草稿；点击“保存配置”持久保存。关闭或 Esc 遇到未保存修改时，可选保存、不保存或取消。校验或存储失败保留草稿。载入、运行和列表管理操作会先保存有效配置。

固定词的棋盘编辑器支持词库搜索、空位匹配、固定位置、自动摆放、撤销和无解提示。这里的“搜索筛选”只改变搜索结果；关卡筛选在主界面或配置行“词库筛选”设置。

批量生成需选择写入的浏览器关卡列表，开始前确认替换与新增数量。配置行显示未生成或关联关卡，可点击跳转。载入某行后单关生成使用同样的配置位置、前序查重历史和后续固定词预留。预留距离按已保存关卡和本轮排队关卡的实际列表位置计算；未运行的配置不占位，跳关后可能相邻的固定词也会预留。

关联元数据为 `sourceConfig: {listId, configId, id, position, levelId?}`。`listId` 是配置列表 ID，`configId` 是配置行 ID；保留旧 `id` 字段供兼容。`levelId` 是配置表中的业务编号（如有）。匹配优先使用所属列表和配置行 ID，兼容旧的来源 ID；同一配置列表内可回退到业务编号。

未生成的配置按同一来源的配置顺序插入。关卡库编号始终按实际顺序连续显示，不为空缺配置创建占位关。例如仅生成配置 050 时，可以显示为关卡 001，并保留“来自配置 050”的来源信息。重跑按关联身份替换，手动调整关卡顺序后仍更新同一记录。

重新读取配置表会创建独立配置列表；不自动认定它与旧列表相同，不静默覆盖旧列表的关联。完整配置备份可从本地版本的 `configs.json` 通过“读取配置 JSON”恢复。JSON 支持配置记录数组、含 `records` 的快照，以及含当前列表的配置库。

### Excel / CSV 配置表

支持下载模板、读取和导出 `.xlsx`，兼容 UTF-8 CSV。Excel 读取第一个工作表。兼容表头保留旧名称：

```text
关卡id,棋盘造型,初始单词1,初始单词2,范围库,情绪,生僻程度
```

可选列为 `目标重复检测` 和 `目标数量`。表头可换顺序，关卡 id 必填且不重复；为保留前导零，请在表格软件中使用文本格式。每行对应一关，全表校验通过后再创建独立列表。

- 棋盘造型：宽×高，例如 `3x3`、`4x3`、`5x3`。这三类分别从给定的 5、8、19 个造型中随机选择，同一关各线程使用同一造型。造型校验失败或一轮 80 次失败后，回退同尺寸矩形。其他尺寸使用矩形；仍兼容旧二维数组造型。
- 初始单词1 / 2：兼容表头，含义是固定词，英文单词或空白，读取后转大写，不预设路径。
- 范围库：`[0,1,2,3,4]`；情绪：`[-2,-1,0,1,2]`；生僻程度：`[1,2,3,4,5]`。全部表示不限，`[]` 表示没有匹配，空白或非法值报错。
- 目标重复检测：0 及以上整数，对应目标词查重范围。目标数量：留空或 0 不自动补选。
- 未列参数使用固定默认值：正向 50%、查重 20 / 20、筛选不限、目标数量 0、无固定路径或豁免，不继承当前界面的隐藏状态。

表格导出包含七项基础列及两项可选列，不包含完整生成参数、固定路径或豁免。超过两个固定词会阻止导出以避免丢词；完整备份应使用配置 JSON。

## 文件与预设

“关卡文件与预设”统一提供本地 JSON 打开、单关 JSON 读取 / 复制、本地版本和参考竞品预设查看。保存文件与另存为仅保留右栏一组。

浏览器关卡使用“保存关卡”写入浏览器库。本地文件的生成或选词修改先写入内存列表并标记未保存，再点击“保存文件”写回；不支持原位写回的浏览器会下载副本。支持新建空白关卡后追加。原文件的未知扩展字段尽量保留。

本地版本和参考竞品预设只读，切换后右侧列表同步显示该来源。它们独立于浏览器编辑关卡，查看不会覆盖浏览器内容；“返回浏览器关卡列表”恢复编辑入口。文件和预设切换会保留各自的编辑状态。

“导出游戏文件”只导出当前浏览器列表已保存结果；未保存的草稿和修改不在导出中。JSON 读取遇到配置文件时，请改用配置列表中的“读取配置 JSON”。

## 数据格式

编辑器关卡快照使用 `records: [{id, level, ...}]`，保存棋盘、路径、目标词、额外词、统计、生成配置和来源。配置快照使用 `records: [{id, config, levelId?}]`；配置与结果分别保存。

游戏导出仍为 `{books, daily}`，所有关卡放入第一册，daily 为空，ID 按实际顺序从字符串 `"1"` 连续编号。每关保留 `id/name/g/t/n/e/lv/ty/curtains` 九个字段；棋盘每行用逗号连接，目标词和额外词各用空格连接。格子次数按目标路径重算，以 36 进制逐格编码。`lv/ty` 为空字符串，`curtains` 为空数组，册 `mix` 为 `[100,0,0,0,0]`。

固定布局为 `{rows, columns, placements: [{word, path}]}`，路径索引从左上角 0 开始逐行编号。`fixedWords` 保存全部固定词，`fixedLayout` 仅保存固定位置的词。

### 兼容字段

旧数据中的 `targetCount`、`targetLengthPlan`、词长上限、总长度上限和旧目标限制开关不再决定生成。`minimumEmotionScore` 不作为生成门槛；情绪仅展示和警告。旧统一查重范围可作为两项范围的初值。旧 `sourceConfig.id`、Excel 表头和已有快照仍可读取。

## 词库

词库在本地 `dist/data/` 运行，普通词、额外词和开场引导词分别加载。仅额外词不能作为目标词；词库筛选同一字段满足任一选中值，不同字段需同时满足。全部选中为不限，全部取消为无匹配。

悬停单词查看词库、范围库、情绪、缩写、生僻档位、音标、释义和来源游戏；有明细时可展开查看实际关卡与词语用途。路径列展示实际路径和路径分，单词的生僻档位直接使用 1～5 原始档位，缺失显示“—”。

关卡难度为所有目标词难度之和。目标词难度 = 实际路径分 + 生僻档位 ×（1 + 长度 × 0.1），例如 5 个字母的长度系数为 1.5，10 个字母为 2.0。初始词只要属于目标词就参与计分，额外词和未选中的候选词不计分；缺少生僻档位或路径分时显示“—”。词列表展示目标词难度，棋盘预览和关卡数据展示总分；统计数据的 `difficulty.total` 保存总分，最多保留两位小数。

词库源数据位于 `data/source/`；修改后执行 `npm run import:words` 重新生成。导入脚本使用 Python 3 标准库。来源游戏和关卡明细使用已有本地快照，不按词库档位推测来源。

## 本地版本

仅在用户明确要求提交本地版本时创建快照和 Git 本地提交，不推送远程。按 Asia/Shanghai 当天日期编号，同日从 v1 递增，不覆盖已有版本。

快照路径：`dist/data/versions/YYYY-MM-DD-vN/`，包含完整关卡、游戏导出和当时配置列表。历史登记在 `dist/data/local-versions.json`。2026-10-28-v1 是确认保留的 20 关（001～020），参考竞品预设与我们的版本独立保存。

自带预设中的“我们的关卡”另收录“新版关卡 · 2026-11-02”，来自桌面 `word-tiles-levels.json`，共 1500 关；保持游戏文件原行序、目标词和格子次数，支持直接下载原文件。此预设独立只读保存，不覆盖浏览器关卡或 2026-10-28-v1 快照。
