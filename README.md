# 方格 · 关卡编辑器

当前仅在本地开发和运行。未经用户明确要求，不向远程推送或发布。关卡及配置保存在当前浏览器本地。

浏览器关卡列表中的「追加导入到浏览器」可读取导出的 `word-tiles-levels.json`（`books` / `daily` 格式），按书册及关卡顺序追加到已有列表，成功后打开首个导入关卡。导入会校验全部关卡并根据棋盘、单词和格子计数还原合法路径、补充词库释义及统计；文件无效或保存失败时不会部分导入。游戏文件未记录初始词与生成参数，导入关卡不标记初始词，生成参数使用默认值。

选择行数、列数（均为 2～5）、棋盘造型、初始正向概率及词库筛选，生成单词关卡。生成不设置目标数量或单词长度限制，先铺满棋盘，再手动筛选目标。

- 默认尺寸为 3 行 × 4 列，共 12 格。
- 支持全部 16 种尺寸组合，格子始终保持正方形。
- 当前尺寸、造型、初始正向概率和词库筛选会保存在浏览器本地；刷新后恢复。浏览器禁止存储时仍可使用编辑功能。
- 点击「恢复默认尺寸」回到 3 行 × 4 列。
- 按电脑端使用场景开发和验证，尺寸选项支持键盘操作。
- 点击「生成关卡」自动选择初始词并填满棋盘，可反复重新生成。
- 右侧「关卡列表」可手动加入当前关卡，保存完整棋盘、单词、路径、统计及生成配置。加入后继续生成不会覆盖列表内容；点击列表项恢复查看及其配置。同一当前结果加入后按钮显示「已加入」，避免重复点击保存。列表使用本地浏览器 IndexedDB 保存，刷新后保留；存储失败时明确提示，不会显示为已加入。
- 每个关卡卡片提供上移、下移和删除按钮，顺序和删除结果自动保存到本地，显示编号按当前顺序连续排列。新加入的关卡排在末尾，查重按当前列表末尾的 N 关计算。删除正在查看的关卡时，保留编辑区中的内容为未加入列表的草稿；调整顺序不改变当前棋盘或未保存的目标词修改。
- 浏览器关卡列表的「导出文件」按已保存列表的当前顺序下载 `word-tiles-levels.json`，兼容旧项目的游戏格式 `{books, daily}`：全部放入第一册，daily 为空，id 从字符串 `"1"` 连续编号。每关固定 `id/name/g/t/n/e/lv/ty/curtains` 九个字段；棋盘按行用逗号连接，目标词与额外词分别用空格连接，使用次数按实际目标路径重算并逐格用 36 进制编码。沿用旧项目的新关卡默认值：`lv/ty` 为空字符串、`curtains` 为空数组、册 `mix` 为 `[100,0,0,0,0]`。这是游戏文件，未加入列表或尚未保存的修改不包含在内；导出不会更改编辑器数据。
- 「目标词查重」和「额外词查重」分别配置范围，默认各 20 关，任一项设为 0 可单独关闭。当前目标词只与最近 N 个已保存关卡的目标词比较，当前额外词只与最近 M 关的额外词比较，跨类别重复不受限制。不足配置关数时检查已有的全部关卡；未加入列表的生成结果不计入历史。任一启用类别出现重复就判定本次生成失败并继续重试。两项范围分别在本地保存，旧版统一范围会作为两项初值；关卡的 `duplicateCheck.target` 和 `duplicateCheck.extra` 分别记录范围和实际比较的关卡编号。
- 词表「目标」列可手动勾选或取消候选词；固定单词不能取消，其他初始词可以在剩余目标覆盖所有启用格子的前提下替换。仅额外词、不符合筛选的词不能勾选；用格歧义仅作提示。操作保持棋盘与路径不变，同步更新目标/额外词归属、格子计数、情绪分和所有统计。已加入列表的关卡修改后点击「保存修改」更新原关卡。
- 未找到满足配置的棋盘时，后台会持续重新生成，直到成功。生成期间按钮变为「停止生成」，可随时停止；修改并应用配置也会取消当前搜索。停止时保留上一个已生成的关卡。悬浮在停止按钮上可查看已完成的尝试次数。
- 单关与批量生成都根据设备运行时报告的逻辑核心数自动并行，使用核心数减 1 个后台 Worker，至少 1 个；无法检测时使用 1 个。多个 Worker 搜索同一关，首个符合条件的结果生效，其余搜索取消。批量仍按配置顺序逐关保存，保证查重历史完整，后续关卡复用已加载的词库。停止运行会终止全部生成线程。配置弹窗与运行进度显示当前并行数。
- 顶栏「关卡配置列表」打开多关配置弹窗，每行独立设置行列、棋盘造型与固定单词、初始正向概率、两项查重范围及词库筛选。可按编辑器当前配置一次新增多关，勾选多行后统一修改指定字段，也可删除所选配置。弹窗内的修改是草稿，点击「保存配置」后保存在本地，直接关闭会放弃未保存修改。点击某行「载入」会先保存整份列表，再将该行设置应用到编辑器并清空当前预览，供下一次生成使用。每个配置列表最多 1500 关，与已生成关卡列表分别保存。
- 配置弹窗顶部可切换当前列表，或点击「新建列表」创建一个命名的空列表，再用「添加」加入关卡。「列表管理」支持切换、重命名、复制和删除；复制会保留棋盘造型、固定词和全部配置，各列表后续独立编辑。新建、切换和管理操作会先保存当前配置；配置无效或存储空间不足时停止操作并保留原数据。删除需确认，至少保留一个列表。旧浏览器配置自动迁移为「原有关卡配置」，刷新会恢复上次所选列表。
- 配置弹窗可直接「运行所选」，或点击「批量生成」填写起始关和结束关。范围按当前配置列表的编号计算，包含起止两关，默认覆盖全部配置；弹窗实时显示关数，取消不启动生成。开始前保存当前配置，按表格顺序逐关生成，成功后自动追加到右侧关卡列表；每关保存完成后才生成下一关，查重包含原有关卡和本轮刚保存的关卡。运行时显示已保存进度、当前配置编号及重试次数，可关闭弹窗观看棋盘，也可随时「停止运行」。已完成配置取消勾选，未完成配置保留勾选；在当前页面点击「运行所选」可继续剩余配置。正在保存的一关会等待保存结果再停止。配置或存储错误会停止队列并保留此前成果，不跳过失败关。运行进度只保留在当前页面，已生成关卡持久保存在本地。
- 单词沿上下左右相邻格子连续排列，可以拐弯，同一单词不会重复经过同一格。
- 不同单词可在任意位置共用多个相同字母，每格右上角只统计最终目标词使用该格的数量。
- 点击目标词、候选词或额外词可高亮其路径，左下角显示路径顺序；再次点击取消高亮。
- 每个单词的「路径」列显示淡蓝灰底棋盘格、加粗连接线和终点箭头，旁边「路径分」显示实际路径的难度。首向上/下/左/右分别为 1/0/1/0 分，每个拐点和每次同轴折返各加 1 分。0 分绿色、1 分蓝色、2 分亮黄色、3 分及以上红色；直线和非直线统一按分数配色，终点箭头与线条同色。
- 调整尺寸、造型或初始正向概率会清空当前关卡，重新生成后使用新配置。
- 单词长度仅受棋盘启用格数与词库内容约束。旧配置和旧关卡中的数量、词长计划、初始词长度上限、总长度上限及全局开关均不再参与生成，也不再提供编辑入口。
- 初始正向概率为 0～100% 的整数，默认 50%。正向指前两个字母向右或向下，反向指向左或向上。每次主动填词时按概率决定优先方向，在能填充同样多空格的合法摆法中先尝试该方向，无可用摆法再尝试另一方向；始终优先覆盖更多空格。0% 优先反向、100% 优先正向，实际正向词占比会受字母布局影响。此配置仅影响初始词填盘，并保存在关卡的 `initialForwardProbability` 字段中。
- 点击「词库筛选」可多选范围库、情绪类型、是否缩写和生僻档位。同一字段满足任意选中值即可，不同字段需同时满足。全部选中表示不限，全部取消则无匹配词；支持重置筛选。
- 「当前关卡所有词」将各类词合并去重，按初始词、关卡目标、额外词、候选词、仅额外排序，同级按字母顺序排列，仅额外词集中在末尾。关卡目标使用绿色整行底色，其余普通底色的词都是额外词，不再显示这两种标签。保留初始词、候选词、仅额外三个标签列，无对应标签时留空；选中路径使用描边，滚动时表头保持可见。
- 工作区固定在当前屏幕内，电脑端采用词表、棋盘、关卡列表三列。关卡卡片保持完整高度，数量增加时在列表内滚动，棋盘随可用空间缩放。
- 词表的「生僻档位」列直接显示词库原始的 1～5 档，缺失值显示为「—」。
- 棋盘上方显示「生僻总分」，等于所有目标词的生僻档位之和；手动增删目标词时同步更新，档位缺失时显示「—」。
- 鼠标悬停单词约 150 毫秒显示左右两栏悬浮卡片：左栏显示所属词库、范围库、情绪、缩写、生僻档位、音标及中英文释义；右栏显示来源游戏，关卡明细展示 Zen Word 的 t1、t3，以及 Word Tiles 的全部版本，按版本列出实际关卡号及目标／额外／仅额外／奖励用途，其他游戏保留来源名称。每个版本默认预览 3 处，其余可展开，悬停关号可看原始 ID。词表、棋盘编辑的搜索结果与固定词、预设关卡中的词共用此逻辑；键盘聚焦也可显示，按 → 进入来源栏。鼠标可移入卡片滚动和展开；移开卡片、滚动外部页面、关闭弹窗或按 Esc 关闭。卡片自动避让屏幕边缘，长释义显示摘要。

## 生成规则

关卡配置列表的「棋盘编辑」显示缩略预览，点击打开编辑面板，可调整尺寸、启用或禁用格子及固定单词。右侧按单词或释义搜索普通词库，每个词可选择「自动摆放」或「固定位置」：自动摆放只保留词名，生成时按初始词规则安排；固定位置需要在左侧依次点击格子，完成后保留路径。两种方式可混合使用，已固定的词也可随时改为自动摆放而不删除词名。手动路径可以拐弯、共用相同字母，不能重复用格或覆盖不同字母。支持撤销一格、取消摆放、重摆、删除和清空。点击「完成」应用草稿，关闭弹窗放弃草稿。自动摆放可跨不同棋盘尺寸批量设置，批量固定位置要求尺寸一致。

生成时先写入固定位置，再按规则摆入自动放置的预设词，最后补满剩余空格；两类预设词全部计入初始词和目标词，不可从生成后的目标列表中移除。它们须放得进启用格子，并遵守词库、手动筛选和查重规则。固定布局和生成结果的用格歧义仅作提示，不阻止生成，固定位置保持不变。`fixedWords` 保留全部预设词名，`fixedLayout` 只保存手动固定位置的 `{rows, columns, placements: [{word, path}]}`，路径索引从左上角 0 开始逐行编号。这两项随配置和保存关卡保留，批量运行、单关重生成均生效。旧配置中未指定位置的词显示为自动摆放。修改尺寸后超出棋盘的固定词需重新摆放或明确改为自动，避免位置被静默丢弃。游戏导出继续使用原来的九字段格式。

「初始词」（关卡数据字段 `initialWords`）专指主动填入棋盘的词；生成完成时它们默认属于关卡目标，关卡目标还可包括从候选词中补选的词；手动筛选可在保持格子覆盖的前提下替换非固定初始词。普通词库是选词来源，并非每个词都会成为初始词。

1. **初始词**：优先选择能填充最多空格的摆法，同等填充量按初始正向概率优先选择起步方向。已有字母相同即可重叠，不限制在首尾。每次必须填入至少一个空格，直到棋盘填满。用格歧义不限制摆放。
2. **候选词**：遍历完整词库及所有合法连接路径，收集棋盘中能拼出的所有不同单词。符合筛选的普通词进入候选集合（包含已放置的初始词），保留路径数量与歧义分析。仅额外词、不符合筛选的词不能进入候选集合。此阶段不计算格子使用次数。
3. **目标词**：生成完成时保留铺满棋盘的初始词作为目标，其余可连词先列为额外词。用户可从符合筛选的候选词中手动增删目标，剩余目标必须覆盖所有启用格子。仅按实际目标词的路径计算每格使用次数。

填盘失败或查重未通过时，会持续重试，不设总尝试次数上限。无效配置、词库加载失败或能事先确认的不可满足条件会直接提示原因。每个单词去重并保留一条有效路径，多个可行路径不会重复计数。初始词保留实际摆放时的路径。

同一个单词存在使用不同格子的合法路径时显示黄色歧义提示；同一组格子的不同连接顺序不视为用格歧义。棋盘编辑中随当前字母动态提示，主编辑区按实际棋盘检查目标词，不依赖旧的 `pathAnalysis.safe` 标记。歧义仅作提示，不阻止单关或批量生成、勾选目标词、保存、导入和导出；连接路径、覆盖、词库筛选、查重等其他规则保持生效。禁用格不参与连接和次数扣减。

旧配置中的 `targetCount`、`targetLengthPlan`、`targetLengthRatios`、`initialMaxWordLength`、`maxWordLength`、`targetLimitsEnabled` 仅为兼容历史数据保留，读取时不会校验或应用这些限制。新配置不写入这些设置；新关卡中的 `targetCount` 记录实际目标数，手动选择后同步更新。

词库筛选同时约束主动填入的初始词和候选转目标词。筛选不删除词库记录，也不限制全量查词；筛选外的可连词仍列为额外词。筛选过严时提示无法生成，不会自动放宽条件。范围库、情绪和生僻档位使用原表数字，不额外解释或重定义其含义。

## 关卡数据

每次生成的关卡在 `statistics` 中保存单关统计，点击棋盘标题栏的「关卡数据」查看。数据包括目标任务量、词长分布、5+/7+占比、生僻档位分布、首向与拐点分布、折返、直线入口、多路径目标词、棋盘字母分布、格子使用次数、候选/额外词数量及占比、情绪总分。

- 词长、词汇和路径统计以全部 `targetWords` 为主体，每词计一次。词库范围内的可连接总数为目标词与额外词之和；可作目标的候选词另列，不重复相加。
- 每个可连接单词的 `pathAnalysis` 保存合法路径数、实际路径分析 `assigned` 与代表路径分析 `representative`；两种分析均包含首向、拐点、折返、方向分 `directionScore` 和难度总分 `difficultyScore`。代表路径按最少拐、最少同轴折返、首向右/下/左/上、坐标序列排序；原 `path` 保持为实际分配路径，格子计数仍按它计算。词表显示实际路径分，关卡数据中的代表路径表显示代表路径分。
- 折返指分别查看水平与竖直方向序列后发生的反向次数。`→↓→` 是两拐零折返，`→↓←` 是两拐一次折返。
- 重复字母格数按每种字母扣除首次出现计算，即格子总数减不同字母数；其占比以格子总数为分母。使用密度为目标字母总数除以格子数。
- 情绪总分为目标词情绪和 × 1 + 额外词情绪和 × 0.3；缺少情绪数据时为 `null`，界面显示「—」。生僻档位缺失单独计数。
- 比例在数据中保存为 0～1，界面显示百分比。不推测玩家行为、跨关历史或综合难度分。

## 单词数据库

原始 `四游戏词库_精简版.xlsx` 导入 22,440 条记录；另有 30 个两字母词（包含 Zen Word 的全部 28 个两字母词）。当前共 22,470 条，分为三个独立词库：普通词库 10,748 条，仅额外词库 11,692 条，2词库 30 条。原文件保存在 `data/source/`，导入过程不修改 Excel。

编辑器可读取的静态数据位于 `dist/data/`：

- `word-bank.json`：字段映射、来源文件校验值、分组数量和数据文件索引。
- `required-words.json`：普通词库，可用于初始填盘和候选转目标。
- `extra-words.json`：仅额外词库，只用于检索额外词。
- `guide-words.json`：2词库，可用于初始填盘和目标词；在「词库筛选 → 范围库」中勾选「2词库」，也可与范围 1～4 混合使用。

原表记录保留原来的 8 个字段、原始值类型与顺序，另加 `id` 和 `sourceRow` 供定位原表。导入不去重、不改大小写、不补全空值，也不根据词长过滤。

| 数据字段 | 原表字段 |
| --- | --- |
| `word` | 单词 |
| `scope` | 范围库 |
| `phonetic` | 音标 |
| `emotion` | 情绪类型 |
| `abbreviation` | 是否缩写 |
| `rarityLevel` | 生僻档位 |
| `definitionEn` | 英文注释 |
| `definitionZh` | 中文注释 |

分类数字保持原表含义与数值，例如「是否缩写」仍保存为 `0` 或 `1`。

`data/source/guide-words.json` 单独保存两字母词：AM、AN、AS、AT、BE、BY、DO、GO、HE、HI、IF、IN、IS、IT、ME、MY、NO、OF、OH、OK、ON、OR、OX、PO、SO、TI、TO、UP、US、WE。每个词包含全部 8 项参数：单词、范围库、音标、情绪类型、是否缩写、生僻档位、英文注释、中文注释。2词库范围值继续使用 `0`，情绪为 `0`；原 28 词生僻档位为 `1`，新增 PO 暂定为 `4`、TI 暂定为 `3`（编辑标注，参考项目未提供这两词的档位）。OK 的缩写值为 `1`，其余为 `0`。记录使用 `guide:` 编号、`sourceRow: null`。导入脚本校验参数后生成独立的 `dist/data/guide-words.json`，并在清单中登记数量、来源和校验值；不会再合并到普通词库。选择范围 1～4 时，两字母词不会成为初始词或目标词；全量额外词检索仍保留所有可连接词。两字母词和其他长度的词按相同的铺盘、筛选和路径安全规则参与生成。

2词库与旧引导库共用 `guide-words.json`、`guide:` 编号和范围值 `0`，已保存的词库筛选仍有效。Zen Word 全版本的 `target / extra / onlyExtra / bonus` 合并去重后有 28 个两字母词，与旧 28 词重合 26 个；新增 PO、TI，保留原 OH、OK。新词的释义和音标分别参考 [Collins · po](https://www.collinsdictionary.com/dictionary/english/po) 与 [Oxford · ti](https://www.oxfordlearnersdictionaries.com/definition/english/ti)，词条保留 `definitionSources` 供核对。生僻档位 1 的初始词规则仍生效，PO、TI 可作为符合筛选和路径安全规则的候选目标。

来源游戏使用参考项目 `data/game_vocab/catalog.json` 的实际全版本、全词类记录，显示去重后的游戏名；未收录的词显示「参考项目暂无记录」，不按词库档位猜测来源。`data/source/word-game-sources.json` 保存来源 SHA256、7 款游戏、28 个 Zen 两字母词及 32,268 个词的游戏位掩码（对应 games 数组顺序），导入时同步到 `dist/data/`，运行不依赖参考项目目录。来源关卡由 Zen Word 与 Word Tiles 的详细资源构建，按首字母压缩保存在 `data/source/word-level-sources/` 和 `dist/data/word-level-sources/`，悬停时按需读取。每个词保存游戏、版本及实际关卡号、原始 ID、用途，多个用途在同一来源位置合并；当前页面显示 Zen Word 的 t1、t3 和 Word Tiles 全部版本的明细，其他游戏保留来源名称。需要更新来源快照时运行 `npm run import:words -- --game-catalog /绝对路径/data/game_vocab/catalog.json`；当前两字母词的参数须先补齐。

以后更新 `data/source/` 中的原词库后，运行 `npm run import:words` 重新生成 JSON。导入脚本使用 Python 3 标准库，无需额外安装依赖。

`required-words.json` 中的词可用于主动填盘，也可从候选词转为目标。原表「额外词」对应的 `extra-words.json` 按「仅额外」处理：只在棋盘能拼出该词时出现在额外词列表，不能主动填盘或成为目标。仅额外标记优先于普通词分类，源数据保持不变。

## 关卡文件、预设与本地版本

顶栏「关卡文件与预设」统一管理三类来源，打开窗口时显示当前正在使用的列表。选择来源和关号会同步到主编辑器；右侧始终显示当前文件名、来源类型和保存状态。

| 来源 | 保存位置与操作 |
| --- | --- |
| 浏览器关卡 | 保存在当前浏览器 IndexedDB；「加入浏览器关卡／保存修改到浏览器」写入浏览器，「导出文件」下载游戏 JSON，「追加导入到浏览器」将文件内容追加到浏览器列表 |
| 本地关卡文件 | 「打开本地关卡文件」后独立编辑；勾选目标、调整顺序、删除、重新生成和读取单关数据都会更新文件草稿，点击「保存文件」才写回原文件；「另存为」保留原文件并转到新文件继续编辑 |
| 自带预设 | 本地版本及参考竞品只读；不写入浏览器关卡，也不会直接修改项目中的预设资源 |

本次打开的多个文件列在同一个来源下拉框中；重复打开未保存的文件会恢复现有草稿，已保存的文件再次打开时读取磁盘最新内容；切换到其他文件、浏览器关卡或自带预设会保留各文件的未保存内容及当前编辑状态。点击「返回浏览器关卡」恢复原浏览器列表和编辑状态。修改棋盘后需先生成完整关卡才能保存；未完成的棋盘可重新点击原关卡恢复。批量生成仍保存到浏览器关卡。

本地文件支持游戏包 `{books, daily}`、单关 `{g,t,n,e,...}` 及编辑器完整快照 `{schemaVersion, records:[{level,...}]}`。保存保持原格式、书册、daily、原关卡 ID、`lv/ty/curtains` 和其他未编辑字段；同册顺序按当前列表保存，跨册移动保持书册边界和容量。编辑器快照保留完整路径、参数和统计。生成配置 JSON 是另一种文件，打开时会明确提示，不能误当成关卡文件覆盖。

Edge / Chrome 在本地服务下通过文件选择器取得文件句柄，首次写入时由浏览器请求写入权限；后续可直接保存，也支持 ⌘/Ctrl+S 和 ⌘/Ctrl+Shift+S。没有文件选择器 API 的浏览器使用普通文件选择和「下载文件副本」，不会声称已覆盖原文件。写入或权限失败保留未保存状态；原文件被其他程序修改时停止覆盖，可先另存为保留当前修改，再重新打开原文件。未保存文件在关闭或刷新页面前由浏览器提醒。文件列表仅保留在本次页面会话，刷新后重新打开文件即可。
