# 方格 · 关卡编辑器

当前仅在本地开发和运行。未经用户明确要求，不向远程推送或发布。关卡及配置保存在当前浏览器本地。

关卡列表中的「导入关卡」可读取导出的 `word-tiles-levels.json`（`books` / `daily` 格式），按书册及关卡顺序追加到已有列表，成功后打开首个导入关卡。导入会校验全部关卡并根据棋盘、单词和格子计数还原合法路径、补充词库释义及统计；文件无效或保存失败时不会部分导入。游戏文件未记录初始词与生成参数，导入关卡不标记初始词，生成参数使用默认值。

选择行数（2 或 3）、列数（3、4 或 5）、目标数量、初始词最长、最长单词长度和初始正向概率，生成单词关卡。

- 默认尺寸为 3 行 × 4 列，共 12 格。
- 支持全部 6 种尺寸组合，格子始终保持正方形。
- 当前尺寸、目标数量、两项单词长度限制、初始正向概率和词库筛选会保存在浏览器本地；刷新后恢复。浏览器禁止存储时仍可使用编辑功能。旧版长度设置会迁移到「初始词最长」，新版「最长单词长度」默认 8。
- 点击「恢复默认尺寸」回到 3 行 × 4 列。
- 按电脑端使用场景开发和验证，尺寸选项支持键盘操作。
- 点击「生成关卡」自动选择初始词并填满棋盘，可反复重新生成。
- 右侧「关卡列表」可手动加入当前关卡，保存完整棋盘、单词、路径、统计及生成配置。加入后继续生成不会覆盖列表内容；点击列表项恢复查看及其配置。同一当前结果加入后按钮显示「已加入」，避免重复点击保存。列表使用本地浏览器 IndexedDB 保存，刷新后保留；存储失败时明确提示，不会显示为已加入。
- 每个关卡卡片提供上移、下移和删除按钮，顺序和删除结果自动保存到本地，显示编号按当前顺序连续排列。新加入的关卡排在末尾，查重按当前列表末尾的 N 关计算。删除正在查看的关卡时，保留编辑区中的内容为未加入列表的草稿；调整顺序不改变当前棋盘或未保存的目标词修改。
- 右侧「导出关卡」按已保存列表的当前顺序下载 `word-tiles-levels.json`，兼容旧项目的游戏格式 `{books, daily}`：全部放入第一册，daily 为空，id 从字符串 `"1"` 连续编号。每关固定 `id/name/g/t/n/e/lv/ty/curtains` 九个字段；棋盘按行用逗号连接，目标词与额外词分别用空格连接，使用次数按实际目标路径重算并逐格用 36 进制编码。沿用旧项目的新关卡默认值：`lv/ty` 为空字符串、`curtains` 为空数组、册 `mix` 为 `[100,0,0,0,0]`。这是游戏文件，未加入列表或尚未保存的修改不包含在内；导出不会更改编辑器数据。
- 「目标词查重」和「额外词查重」分别配置范围，默认各 20 关，任一项设为 0 可单独关闭。当前目标词只与最近 N 个已保存关卡的目标词比较，当前额外词只与最近 M 关的额外词比较，跨类别重复不受限制。不足配置关数时检查已有的全部关卡；未加入列表的生成结果不计入历史。任一启用类别出现重复就判定本次生成失败并继续重试。两项范围分别在本地保存，旧版统一范围会作为两项初值；关卡的 `duplicateCheck.target` 和 `duplicateCheck.extra` 分别记录范围和实际比较的关卡编号。
- 词表「目标」列可手动勾选或取消候选词；初始词锁定为目标，仅额外词和不符合筛选的词不能勾选。操作保持棋盘与路径不变，同步更新目标/额外词归属、格子计数、情绪分和所有统计。手动修改不受自动生成的数量/词长配置限制，原生成配置保留供下次生成使用，实际目标以 `targetWords` 和统计为准。已加入列表的关卡修改后点击「保存修改」更新原关卡。
- 未找到满足配置的棋盘时，后台会持续重新生成，直到成功。生成期间按钮变为「停止生成」，可随时停止；修改并应用配置也会取消当前搜索。停止时保留上一个已生成的关卡。悬浮在停止按钮上可查看已完成的尝试次数。
- 单关与批量生成都根据设备运行时报告的逻辑核心数自动并行，使用核心数减 1 个后台 Worker，至少 1 个；无法检测时使用 1 个。多个 Worker 搜索同一关，首个符合条件的结果生效，其余搜索取消。批量仍按配置顺序逐关保存，保证查重历史完整，后续关卡复用已加载的词库。停止运行会终止全部生成线程。配置弹窗与运行进度显示当前并行数。
- 点击「关卡目标词」展开配置面板，设置目标数量；启用「逐个配置词长」后，每个目标词提供一行三个切换选项：短词（3 字母）、中词（4 字母）、长词（5 字母及以上），点击即可选中。面板显示各类词数，增加数量时补充新的配置项，减少时移除末尾项。点击「完成」应用；关闭面板放弃尚未应用的修改。默认仅限制数量，逐词编辑面板最多支持 1000 项。
- 顶栏「关卡配置列表」打开多关配置弹窗，每行独立设置行列、目标数量与逐个词长、两项长度限制、初始正向概率、两项查重范围及词库筛选。可按编辑器当前配置一次新增多关，勾选多行后统一修改指定字段，也可删除所选配置。弹窗内的修改是草稿，点击「保存配置」后保存在本地，直接关闭会放弃未保存修改。点击某行「载入」会先保存整份列表，再将该行设置应用到编辑器并清空当前预览，供下一次生成使用。配置列表最多 1500 关，与已生成关卡列表分别保存。
- 配置弹窗可直接「运行所选」，或点击「批量生成」填写起始关和结束关。范围按当前配置列表的编号计算，包含起止两关，默认覆盖全部配置；弹窗实时显示关数，取消不启动生成。开始前保存当前配置，按表格顺序逐关生成，成功后自动追加到右侧关卡列表；每关保存完成后才生成下一关，查重包含原有关卡和本轮刚保存的关卡。运行时显示已保存进度、当前配置编号及重试次数，可关闭弹窗观看棋盘，也可随时「停止运行」。已完成配置取消勾选，未完成配置保留勾选；在当前页面点击「运行所选」可继续剩余配置。正在保存的一关会等待保存结果再停止。配置或存储错误会停止队列并保留此前成果，不跳过失败关。运行进度只保留在当前页面，已生成关卡持久保存在本地。
- 单词沿上下左右相邻格子连续排列，可以拐弯，同一单词不会重复经过同一格。
- 不同单词可在任意位置共用多个相同字母，每格右上角只统计最终目标词使用该格的数量。
- 点击目标词、候选词或额外词可高亮其路径，左下角显示路径顺序；再次点击取消高亮。
- 每个单词的「路径」列显示淡蓝灰底棋盘格、加粗连接线和终点箭头，旁边「路径分」显示实际路径的难度。首向上/下/左/右分别为 1/0/1/0 分，每个拐点和每次同轴折返各加 1 分。0 分绿色、1 分蓝色、2 分亮黄色、3 分及以上红色；直线和非直线统一按分数配色，终点箭头与线条同色。
- 调整尺寸、目标数量、初始词最长、最长单词长度或初始正向概率会清空当前关卡，重新生成后使用新配置。
- 「初始词最长」（`initialMaxWordLength`）默认 8，限制初始词长度；「最长单词长度」（`maxWordLength`）默认 8，限制全部关卡目标，包括初始词和候选转目标词。初始填盘同时遵守两项上限，例如初始设 4、最长设 6，主动摆词最多 4 字母，后续目标可以使用 5～6 字母词。初始上限高于总上限时按较小值填盘。完整检索仍保留所有可连接词，超出总上限的词只能成为额外词，不参与目标补选。
- 初始正向概率为 0～100% 的整数，默认 50%。正向指前两个字母向右或向下，反向指向左或向上。每次主动填词时按概率决定优先方向，在能填充同样多空格的合法摆法中先尝试该方向，无可用摆法再尝试另一方向；始终优先覆盖更多空格。0% 优先反向、100% 优先正向，实际正向词占比会受字母布局影响。此配置仅影响初始词填盘，并保存在关卡的 `initialForwardProbability` 字段中。
- 点击「词库筛选」可多选范围库、情绪类型、是否缩写和生僻档位。同一字段满足任意选中值即可，不同字段需同时满足。全部选中表示不限，全部取消则无匹配词；支持重置筛选。
- 「当前关卡所有词」将各类词合并去重，按初始词、关卡目标、额外词、候选词、仅额外排序，同级按字母顺序排列，仅额外词集中在末尾。关卡目标使用绿色整行底色，其余普通底色的词都是额外词，不再显示这两种标签。保留初始词、候选词、仅额外三个标签列，无对应标签时留空；选中路径使用描边，滚动时表头保持可见。
- 工作区固定在当前屏幕内，电脑端采用词表、棋盘、关卡列表三列。关卡卡片保持完整高度，数量增加时在列表内滚动，棋盘随可用空间缩放。
- 词表的「生僻档位」列直接显示词库原始的 1～5 档，缺失值显示为「—」。
- 棋盘上方显示「生僻总分」，等于所有目标词的生僻档位之和；手动增删目标词时同步更新，档位缺失时显示「—」。
- 鼠标悬浮在单词上显示词库释义，优先中文，无中文时使用英文，两者均缺失时显示「暂无释义」。

## 生成规则

关卡配置列表的「固定单词」打开棋盘编辑面板。右侧按单词或释义搜索普通词库，每个词可选择「自动摆放」或「固定位置」：自动摆放只保留词名，生成时按初始词规则安排；固定位置需要在左侧依次点击格子，完成后保留路径。两种方式可混合使用，已固定的词也可随时改为自动摆放而不删除词名。手动路径可以拐弯、共用相同字母，不能重复用格或覆盖不同字母。支持撤销一格、取消摆放、重摆、删除和清空。点击「完成」应用草稿，关闭弹窗放弃草稿。自动摆放可跨不同棋盘尺寸批量设置，批量固定位置要求尺寸一致。

生成时先写入固定位置，再按规则摆入自动放置的预设词，最后补满剩余空格；两类预设词全部计入初始词和目标词，不可从生成后的目标列表中移除。它们占用目标数量及词长名额，遵守初始词最长、总词长、普通词库、筛选、初始生僻档位和查重限制。固定布局已经存在用格歧义时直接提示；补盘后才出现歧义则重新尝试，固定位置保持不变。`fixedWords` 保留全部预设词名，`fixedLayout` 只保存手动固定位置的 `{rows, columns, placements: [{word, path}]}`，路径索引从左上角 0 开始逐行编号。这两项随配置和保存关卡保留，批量运行、单关重生成均生效。旧配置中未指定位置的词显示为自动摆放。修改尺寸后超出棋盘的固定词需重新摆放或明确改为自动，避免位置被静默丢弃。游戏导出继续使用原来的九字段格式。

「初始词」（关卡数据字段 `initialWords`）专指主动填入棋盘的词；它们全部属于关卡目标，关卡目标还包括从候选词中补选的词。普通词库是选词来源，并非每个词都会成为初始词。

1. **初始词**：每次在所有合法摆法中优先选择能填充最多空格的摆法。同等填充量按初始正向概率优先选择起步方向。已有字母相同即可重叠，不限制在首尾。每次必须填入至少一个空格，直到棋盘填满。
2. **候选词**：遍历完整词库及所有合法连接路径，收集棋盘中能拼出的所有不同单词。符合筛选、且所有路径都使用相同一组格子的普通词进入候选集合（包含已放置的初始词）。仅额外词、不符合筛选的词和存在用格歧义的词进入额外集合。初始词或固定词出现用格歧义时重新生成整个棋盘。此阶段不计算格子使用次数。
3. **目标词**：保留全部初始词，从其他符合筛选的普通候选词中，按词表显示的实际路径分从低到高补足目标，同分随机选择，使最终目标数量严格等于配置值。启用逐个词长配置时，初始词计入相应名额，每一类分别补足最低分候选，再按配置顺序排列 `targetWords`。「仅额外」词不参与选择，无论其分数多低。剩余候选词全部成为额外词。最后仅按目标词的路径计算每格使用次数。

目标数量默认 6，可在界面调整。填盘失败、初始词超过目标数量、候选不足或长度配额不满足时，会持续重试，不设总尝试次数上限，也不减少目标数量或放宽条件。无效配置、词库加载失败或能事先确认的不可满足条件会直接提示原因。每个单词去重并保留一条有效路径，多个可行路径不会重复计数。初始词保留实际摆放时的路径。

路径安全检查允许同字母和多条路径，但目标词的每一种合法连法必须消耗同一组格子；路线顺序可以不同。`pathAnalysis.safe` 记录完整枚举后的结果，不因达到路径数量上限而将未检查的词判为安全。配合按目标词计算的格子次数，任意出词顺序和连法都会保留剩余目标的用格需求。额外词不消耗次数，因此不受此限制。手动加目标词和导出会根据实际棋盘重新检查，不依赖旧数据中的标记。旧关卡仍可查看和导入；有歧义时显示具体单词并阻止导出，非初始目标可移除，初始词需重新生成。

逐个词长配置直接统计每类词的数量，初始填盘也遵守这些名额。词库、最长单词长度或初始长度无法满足配置时明确报错，不自动放宽条件。关卡中的 `targetLengthPlan` 按顺序保存 `short` / `medium` / `long`，`targetLengthCounts` 保存各类数量；未启用时两者为 `null`。旧百分比配置和旧关卡按原来的整数配额换算为逐项配置，兼容字段 `targetLengthRatios` 在新配置中为 `null`。词表仍使用初始词优先等原有排序，关卡数据中的目标词数组保留配置顺序。

词库筛选同时约束主动填入的初始词和候选转目标词。筛选不删除词库记录，也不限制全量查词；筛选外的可连词仍列为额外词。筛选过严时提示无法生成，不会自动放宽条件。范围库、情绪和生僻档位使用原表数字，不额外解释或重定义其含义。

## 关卡数据

每次生成的关卡在 `statistics` 中保存单关统计，点击棋盘标题栏的「关卡数据」查看。数据包括目标任务量、词长分布、5+/7+占比、生僻档位分布、首向与拐点分布、折返、直线入口、多路径目标词、棋盘字母分布、格子使用次数、候选/额外词数量及占比、情绪总分。

- 词长、词汇和路径统计以全部 `targetWords` 为主体，每词计一次。词库范围内的可连接总数为目标词与额外词之和；可作目标的候选词另列，不重复相加。
- 每个可连接单词的 `pathAnalysis` 保存合法路径数、实际路径分析 `assigned` 与代表路径分析 `representative`；两种分析均包含首向、拐点、折返、方向分 `directionScore` 和难度总分 `difficultyScore`。代表路径按最少拐、最少同轴折返、首向右/下/左/上、坐标序列排序；原 `path` 保持为实际分配路径，格子计数仍按它计算。词表显示实际路径分，关卡数据中的代表路径表显示代表路径分。
- 折返指分别查看水平与竖直方向序列后发生的反向次数。`→↓→` 是两拐零折返，`→↓←` 是两拐一次折返。
- 重复字母格数按每种字母扣除首次出现计算，即格子总数减不同字母数；其占比以格子总数为分母。使用密度为目标字母总数除以格子数。
- 情绪总分为目标词情绪和 × 1 + 额外词情绪和 × 0.3；缺少情绪数据时为 `null`，界面显示「—」。生僻档位缺失单独计数。
- 比例在数据中保存为 0～1，界面显示百分比。不推测玩家行为、跨关历史或综合难度分。

## 单词数据库

已导入 `四游戏词库_精简版.xlsx`，共 22,440 条记录：普通词库 10,748 条，仅额外词库 11,692 条。原文件保存在 `data/source/`，导入过程不修改 Excel。

编辑器可读取的静态数据位于 `dist/data/`：

- `word-bank.json`：字段映射、来源文件校验值、分组数量和数据文件索引。
- `required-words.json`：普通词库，可用于初始填盘和候选转目标。
- `extra-words.json`：仅额外词库，只用于检索额外词。

每条记录保留原来的 8 个字段、原始值类型与顺序，另加 `id` 和 `sourceRow` 供定位原表。导入不去重、不改大小写、不补全空值，也不根据词长过滤。

| 数据字段 | 原表字段 |
| --- | --- |
| `word` | 单词 |
| `scope` | 范围库 |
| `phonetic` | 音标 |
| `emotion` | 情绪类型 |
| `abbreviation` | 是否缩写 |
| `rarityLevel` | 生僻档位 |
| `definitionEn` | 英文注释 |
| `definitionZh` | 中文注释 |

分类数字保持原表含义与数值，例如「是否缩写」仍保存为 `0` 或 `1`。

以后更新 `data/source/` 中的原词库后，运行 `npm run import:words` 重新生成 JSON。导入脚本使用 Python 3 标准库，无需额外安装依赖。

`required-words.json` 中的词可用于主动填盘，也可从候选词转为目标。原表「额外词」对应的 `extra-words.json` 按「仅额外」处理：只在棋盘能拼出该词时出现在额外词列表，不能主动填盘或成为目标。仅额外标记优先于普通词分类，源数据保持不变。
